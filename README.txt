KING E-COMMERCE AI PWA prototype
Files: index.html, manifest.webmanifest, sw.js, icon.svg
This is a local-data prototype. It does not connect to suppliers, accept payments, or place orders. Do not enter sensitive customer data.
Publish on an HTTPS host whose terms allow the intended business use. GitHub Pages terms prohibit using its free hosting primarily to run an online business, e-commerce site, or commercial SaaS. GitHub can store the source code, but use a suitable host for the live app.
After publishing on HTTPS, open the site in Chrome and use menu > Install app or Add to Home screen. PWA installation/offline support requires HTTPS.
